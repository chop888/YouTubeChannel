# YouTubeChannel
## 自動化しやすい工程

**1. リサーチ・台本作成**
- Claude(API/Claude Code)にテーマ調査→構成案→台本生成をさせる
- Web検索ツールと組み合わせれば、最新ニュースや資料の要約から台本の元ネタを作れる
- 「2人のキャラの掛け合い」形式なら、話者ごとにセリフを振り分けるプロンプト設計がカギ

**2. 音声合成**
- 台本テキストをVOICEVOX/CeVIO等のAPIに投げてWAV生成→これは完全にスクリプト化可能
- Claude Codeに「台本→音声ファイル一式」まで一気通貫でやらせられる

**3. YMM4上のタイムライン組み立て**
- YMM4はプロジェクトファイル(.ymmp)がテキスト(JSON的な構造)なので、台本+音声の長さから字幕・立ち絵の切り替えタイミングを自動生成するスクリプトが書ける
- ここはClaude Codeでのツール開発が一番効いてくる部分です(既存の自動化ツール・プラグインも公開されています)

**4. サムネイル・タイトル案**
- 台本内容からタイトル案/サムネ文言をClaudeに複数案出させる
- 画像自体は別途生成ツールが必要

**5. 投稿・分析**
- YouTube Data APIで予約投稿、再生数・維持率データの取得は自動化可能
- 「伸びている話題」のリサーチにも使える

## 自動化が難しい/人が見るべき部分
- 最終的な動画の質チェック(誤読・違和感のあるテンポ)
- サムネ・タイトルの最終選定(CTRに直結するため人の勘が重要)
- 著作権・素材のライセンス確認

## 「裏で24時間Claude Codeを動かす」場面について

Claude Codeは基本的に**対話的なターミナルツール**なので、それ自体が「24時間常駐して待ち構える」動き方はしません。常時稼働のイメージが生まれるのは、こういうケースです。

**① 定期実行(cron/スケジューラ)**
「1日1本、テーマを決めて台本→音声→タイムライン組み立てまで自動生成する」といったジョブを、`claude -p`(ヘッドレスモード)でcronから毎日決まった時刻に叩く形。これが最も現実的な「自動チャンネル運用」の形で、常時プロセスが立ちっぱなしというより**間欠的にジョブが起動する**イメージです。

**② 長時間タスクの単発実行**
「今月分30本のリサーチと台本を一気に作る」のようなバッチ処理を投げると、その処理が終わるまで数時間〜半日ほど動き続けることはあります。これは"待機"ではなく"実行中"が長いパターンです。

**③ CI/GitHub Actions連携**
台本や設定ファイルをGitリポジトリで管理し、pushやIssue登録をトリガーにClaude Codeが自動で動く(GitHub Actions経由)構成。イベント駆動なので、これも常時稼働ではなく「トリガーが来たら起動」です。

**④ 監視・自己修復ループ**
自作の投稿パイプラインで「エラーが出たら検知して直す」ような監視スクリプトを常駐させ、そこからClaude Codeを都度呼び出す構成。この"監視側のスクリプト"自体は常時起動になりますが、Claude Code本体はそのたびに短時間だけ呼ばれる形が一般的です。

つまり「Claude Codeプロセスそのものを24時間張り付かせる」というより、**軽量な常駐スケジューラ(cronやGitHub Actions)がトリガーとなり、Claude Codeを都度ヘッドレスモードで起動する**という設計が現実的で、コスト面でも安全です。API従量課金になるため、無制限に走らせるとコストが跳ねる点は要注意です。

## ディレクトリ構成

```
YouTubeChannel/
├── README.md                      # リポジトリ全体の説明、チャンネル一覧
├── shared/                        # 複数チャンネルで使い回すもの
│   ├── voicevox-config/           # 音声合成の共通設定
│   └── scripts/                   # 汎用の自動化スクリプト（共通処理）
│
└── channels/
    └── food-convenience/          # 食（コンビニ・スーパー比較）チャンネル
        ├── docs/
        │   ├── 01-concept.md          # テーマ・型・フォーマットの決定事項
        │   ├── 02-script-templates.md # 台本テンプレ（比較型・〇選型）
        │   └── 03-automation.md       # このチャンネル専用の自動化設計
        ├── characters/                # 立ち絵素材、表情差分パーツ
        ├── assets/                    # 自作イラスト画像素材
        ├── scripts/                   # 台本の完成データ・生成ロジック
        ├── research/                  # 競合リサーチ結果、企画ネタのストック
        └── output/                    # 完成した.ymmpファイル、書き出し情報
```

## 各チャンネルの追加方法

新しいチャンネルを追加する場合は、`channels/` 配下に同じ構成のフォルダを作成してください。

```
channels/
└── <新チャンネル名>/
    ├── docs/
    ├── characters/
    ├── assets/
    ├── scripts/
    ├── research/
    └── output/
```
