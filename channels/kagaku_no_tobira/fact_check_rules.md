# ファクトチェック・ダブルチェックルール

## 1. 情報源の優先順位
1. 最優先:確立した一次情報(論文、NASA/JAXA等の公式発表、政府機関、学会発表)
   - 査読済みか未査読(プレプリント)かを確認し、記録する
   - 確認方法:①arXiv・bioRxiv等のプレプリントサーバーに掲載されている場合は未査読と判断する ②Nature・Science等の査読制度がある学術誌・学会誌に掲載されている場合は査読済みと判断する
   - 未査読の場合は動画内で「まだ研究段階」「未査読の報告」等、断定を避けた表現にする
2. 仮説・未証明理論:科学者・研究者が提唱している仮説で、まだ結論が出ていないもの
   - 「誰が」「いつ」提唱した仮説かを明示する
   - 「〇〇という仮説がある」「まだ証明されていない」と、未証明であることを動画内で明言する
   - 可能であれば、その仮説に対する懐疑的な意見・反論も一言添える
   - 出所不明の噂・都市伝説とは明確に区別する(提唱者・議論の場が実在するかを確認する)
3. 次点:大手メディアの科学欄、専門家監修記事
4. 参考(出発点としてのみ使用可):Wikipedia。最終的な出典としては使わない
5. 避ける:出所不明の噂・個人の憶測・SNSの又聞き(提唱者や議論の実在が確認できないもの)

## 2. 英語原文の確認
NASA/JAXA等、英語が原文の一次情報は、AIの翻訳・要約を鵜呑みにせず、英語原文の該当箇所を必ず確認する。

## 3. 複数ソースでの裏取り
その動画のタイトル・サムネイルの核心となる主張(動画の看板となる情報)は、独立した2ソース以上で確認する。
それ以外の補足・背景説明にあたる情報は、1ソース+出典明記で可とする。
→ 核心となる主張で2ソース目が見つからない場合は、その主張だけ表現を弱める(「〜という報告がある」等)か、その1点のみ動画から外す。テーマ自体を没にしない。

## 4. 表現ルール
- 学説が分かれているテーマは「〇〇という説が有力です」「まだ研究段階です」と書き、断定しない
- 「絶対」「必ず」等の強い断定語は使わない
- 人体・医療系は特に「診断・治療を推奨する表現」を避ける(未証明の仮説でも、健康被害につながりうる内容は特に慎重に扱う)
- 最新ニュース性の高い情報は「◯年◯月時点の情報」と時点を明記する
- 数値・統計を使う際は出典を明記する
- 動画の概要欄に出典を記載する
- タイトル・サムネイルは本編の内容と齟齬がないか確認する(誇張・釣りにしない)
- 使用する図解・CG・資料映像も、現象を誤って表現していないか確認する

## 5. チェック工程(1人+AI体制)
1. 1回目:AIに情報収集させる(一次情報を中心に、英語原文も確認)
2. 2回目:別セッション、または1回目の回答を見せない状態で、独立に「この主張に反論・異説・最新の反証はないか」を再調査させる(同一セッションでの聞き直しはしない)
3. AIが提示した固有名詞・数値・引用元URL・論文タイトルは、実際にアクセスして実在するか個別に確認する
4. 出典URLとアクセス日を調査ログ(videos/<テーマ名>/research.md)に記録する
5. ソース間で矛盾が見つかった場合は、両論併記するか、判断できない場合はそのネタを見送る

## 6. 公開前の最終チェック項目
- [ ] 使用した情報源はすべて一次情報 or 信頼できる媒体か
- [ ] 査読済み/未査読、または仮説段階であることを記録し、それに応じた表現になっているか
- [ ] 断定しすぎている表現がないか
- [ ] 医療・健康に関する助言的な表現になっていないか
- [ ] 情報の時点(最新性)を明記しているか
- [ ] AIが生成した固有名詞・数値・出典URLを個別に実在確認したか
- [ ] タイトル・サムネイルが本編内容と齟齬がないか
- [ ] 使用素材(画像・映像)の著作権・出典を確認したか
- [ ] 台本が調査ログの内容と齟齬なく、掛け合い演出による誇張・単純化で意味が変わっていないか

## 7. 公開後の運用
- 誤りが判明した場合は、概要欄と固定コメントで訂正する
- 総集編・ハイライト動画を作成する際は、素材となる過去動画に後から訂正が入っていないか確認する
