# キャラクター設定

## えりか（進行役）

| 項目 | 内容 |
|---|---|
| 役割 | 商品情報や比較ポイントを整理して伝える。動画の進行管理役 |
| 一人称 | わたし |
| 性格イメージ | 落ち着いている、少し几帳面、リサーチ好き |
| 口調イメージ | 「今日はこの3つを比較していくね」「実は〇〇円の差があるの」 |
| 動画内での機能 | 商品紹介・データ提示・話をまとめる |

## ここな（リアクション役）

| 項目 | 内容 |
|---|---|
| 役割 | 視聴者目線で驚いたり質問したりする。テンポを作る |
| 一人称 | うち |
| 性格イメージ | 素直、テンションが上がりやすい、庶民的な金銭感覚 |
| 口調イメージ | 「えっ、それ知らんかった！」「うちそれ絶対買う」 |
| 動画内での機能 | 感情の起伏を作る、視聴者の"言いたいこと"を代弁する |

## 見た目・世界観

- 人間・日常系（学生・会社員風）
- 制作者本人と友人の写真をベースにデザイン
- モデルと分からないよう、髪色などの特徴は変更して制作する

## 台本設計上の注意

- 「わたし」「うち」で一人称を分けているため、字幕なしでも聞き分けやすい設計にしている
- 台本生成プロンプトを作る際は、上記の口調イメージ・一人称を必ず反映させる

## 音声設定（VOICEVOX）

| キャラクター | VOICEVOXキャラクター |
|---|---|
| えりか（進行役） | あいえるたん |
| ここな（リアクション役） | 東北イタコ |

### クレジット表記について

動画の概要欄に、使用したVOICEVOXキャラクターのクレジットを記載する（動画本編への焼き込みは不要）。
正確な文言は、各キャラクターの利用規約ページに記載されたものをそのまま使用する。

## 立ち絵素材のフォルダ構成（YMM4）

```
えりか/
├── 目/（目.png・目.0.png）
├── 口/（口.png・口.0.png）
└── 体/（体.png＝ベース、驚き.png・笑顔.png等の表情差分もここに格納）
```

ここなも同様の構成。

## 表情差分の切り替え方法

- 「体」フォルダに表情差分の画像（驚き・笑顔・がーん等）をまとめて格納し、「体」のプルダウンから選択して切り替える
- 目・口は「未選択」にすることで、表情差分の1枚絵（目・口込み）がそのまま表示される
- よく使う組み合わせは「表情」欄の保存機能でプリセット登録しておくと、都度の再設定が不要になる

## 汗・「!」マーク等の装飾パーツ

- キャラクターの立ち絵パーツとは別に、通常の画像アイテムとしてタイムラインに配置する
- 「Y」の移動設定（直線移動／加減速移動）を使うことで、垂れる・跳ねるといった簡易アニメーションを付けられる
