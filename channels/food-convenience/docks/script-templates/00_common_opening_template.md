# 共通オープニング（全テンプレ共通・固定）

チャンネル名決定（プチ得ラボ）に伴い、すべての台本テンプレートの「導入」セクションの
一番最初に、以下の固定挨拶を必ず挿入する。

## 固定セリフ（約5秒）

```
えりか：どうも、えりかです。
ここな：ここなだよ！
えりか：プチ得ラボ、始めていくね。
```

この直後に、各テンプレ本来の導入（お題提示・つかみのフレーズ）を続ける。

### 例：比較型（3項目）の場合

```
えりか：どうも、えりかです。
ここな：ここなだよ！
えりか：プチ得ラボ、始めていくね。
えりか：みんな、マーラータンって好き？
ここな：うちめっちゃ好き！最近ハマってて、週2くらいで食べてるかも。
えりか：今日はセブン・ローソン・ファミマ、比較していくね。
```

## 反映対象テンプレート（6種）

- 比較型（2項目）
- 比較型（3項目）
- おすすめ〇選型
- 雑学系
- 単品ディープダイブ型
- 定点観測・値上げ値下げ追跡型

いずれのテンプレートも、「導入」セクションの一番先頭にこの固定セリフを追加し、
既存の導入セリフはそのまま後ろに続ける形にする。

## 尺への影響

固定挨拶の分（約5秒）だけ、各テンプレートの全体尺がわずかに伸びる。
総尺を10分ちょうどに収めたい場合は、総括パートを数秒短縮するなど、
どこか別の箇所で微調整する。無理に導入を短縮する必要はない。

## 運用ルール

- この固定挨拶は、**チャンネルの通常運用（2本目以降）でも毎回入れる**方針とする
- 以前検討した「初回動画のみフル自己紹介、以降は名前テロップのみ」という案からは変更し、
  短い固定フレーズとして定着させることで、視聴者への安心感とブランド認知を優先する

  ## 画面演出：「はじめに」バッジ（固定オープニングとセット）

固定オープニングのセリフが流れている間、画面右上に「はじめに」の文字を
四角いバッジ状のテロップで表示する。

- 表示タイミング：固定オープニングの開始と同時に表示、オープニング終了と同時に消える
- デザイン：四角形＋テキストの組み合わせ、白背景に黒文字のシンプルなデザイン
- エフェクト：登場退場ともに「フェードイン・アウト」を適用
- 一度作成したら、映像エフェクトの「テンプレート」機能で保存し、
  以降は選ぶだけで再現できるようにする

## パート切り替え時の「章タイトル」演出（全テンプレ共通）

比較型など、複数の対象（企業・商品など）を順番に扱うテンプレートでは、
各パートが始まる直前に、以下の演出を挿入する。

- 単色の図形（画面全体を覆うサイズ、チャンネルカラー系の色）を配置
- その中央に、これから扱う対象名（例：「セブンイレブン」）のテキストを重ねる
- 図形・テキストの両方に「フェードイン・アウト」エフェクトを適用
- 表示時間は1〜2秒程度の短さにする
- 図形とテキストはグループ化しておき、他のパートにも複製して使い回す

この演出により、視聴者が「新しいパートが始まった」ことを
字幕を読まなくても直感的に把握できるようにする。

## 固有名詞・シリーズ名の事実確認ルール（全テンプレ共通）

台本内で、企業の商品シリーズ名・キャンペーン名・製法名などの
固有名詞を使う場合は、必ず一度、実在するかWeb検索等で確認すること。

- AIが生成した固有名詞は、実在しない名称（ハルシネーション）である
  可能性があるため、公開前に必ず裏取りを行う
- 確認が取れない固有名詞は、使用せず、一般的な表現に置き換える
  （例：「おにぎり屋シリーズ」→確認できなければ「変わり種シリーズ」
  のような、固有名詞に依存しない表現にする）
- 価格情報と同様に、固有名詞も「事実確認が必要な情報」として扱う
