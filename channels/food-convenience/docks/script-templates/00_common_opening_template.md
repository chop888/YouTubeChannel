# 共通オープニング（全テンプレ共通・固定）

チャンネル名決定（プチ得ラボ）に伴い、すべての台本テンプレートの「導入」セクションの
一番最初に、以下の4ステップ構成のオープニングを必ず挿入する。

## オープニングの構成（4ステップ）

1. **名乗り**：えりか・ここなの自己紹介（固定・全テンプレ共通）
2. **あるあるフック**：本題と少し関係のある、視聴者が共感できる日常の「あるある」話題。
   本題そのものではなく、一歩手前の共感入り口とする
3. **本題への接続**：「そこで今日は〇〇を紹介するよ」等で、あるあるフックから本題へ繋げる
4. **画面切り替え演出**：チャンネル名「🔬 プチ得ラボ」を表示する画面へ切り替える

以前あった「はじめに」バッジは廃止し、このチャンネル名画面のみを
オープニングの区切り演出として扱う。

## ステップ1：名乗り（固定セリフ・約2秒）

```
えりか：どうも、えりかです。
ここな：ここなだよ！
```

## ステップ2：あるあるフック（各テンプレ側で用意・目安5〜10秒）

本題（比較する商品・紹介するテーマ等）の名前をいきなり出すのではなく、
テーマよりもう一段階広い、日常の悩み・シーンへの共感を先に挟む**2段階構成**にする。
（参考：「暑い時、めんどくさい時にカロリーを摂りたくなる」のような、テーマそのものに
触れない、もっと広い日常の共感を先に挟んでから、初めて具体的なテーマ名を出す構成）

- **1段階目（フック）**：えりかが、テーマ名・商品名に触れない、もっと広い日常の
  悩み・シーンを問いかける（例：「忙しい朝とか、パパッと済ませたいランチの時って
  どうしてる？」）
- **2段階目（つなぎ）**：ここなが、その日常シーンへの自分なりの答えとして、
  自然とテーマのジャンル（商品カテゴリ）に触れる形で共感を返す
  （例：「うち、そういう時は大体コンビニでおにぎり買っちゃうかも」）
- えりかが軽く相槌・橋渡しの一言を挟む
  （例：「だよね、手軽さで言ったらコンビニおにぎりって最強だと思う」）

このフック部分では、テーマのジャンル（例：おにぎり）が会話の流れで自然に
出てくるのは問題ないが、**今日扱う具体的な比較対象・順位・雑学ネタなど、
「今日の内容そのもの」はまだ明示しない**。それはステップ3（本題への接続）で
初めて出す。

- 「いきなりだけど」のような唐突な前置きフレーズは使わない（フック自体が自然な導入になる）
- 具体的な例文は、各テンプレートファイル（comparison-2items.md 等）の
  「導入」セリフ骨格に、その型に合った内容で用意する

## ステップ3：本題への接続

あるあるフックを受けて、「そこで今日は〇〇を紹介するよ」のような形で自然に本題へ繋げる。
これまでの「お題提示」に相当する部分。

## ステップ4：画面演出（チャンネル名表示・オープニングの区切り）

名乗り〜本題への接続のセリフが終わったタイミングで、画面を切り替え、
チャンネル名「🔬 プチ得ラボ」を表示する。この画面演出が、オープニングと
本編（各パート）の区切りとして機能する。

- 表示内容：「🔬 プチ得ラボ」のロゴ／テキスト
- デザイン：画面全体を覆うシンプルな構成、チャンネルカラーを基調にする
- エフェクト：登場退場ともに「フェードイン・アウト」を適用
- 表示時間：1〜2秒程度
- 一度作成したら、映像エフェクトの「テンプレート」機能で保存し、
  以降は選ぶだけで再現できるようにする

### 例：比較型（3項目）の場合

```
えりか：どうも、えりかです。
ここな：ここなだよ！
えりか：小腹が空いた時とか、ちょっとした贅沢がしたい時ってどうしてる？
ここな：うち、最近は麻辣系のピリ辛おやつにハマってて、それで満足してるかも。
えりか：だよね、あれ手軽にガツンと満足感あるもんね。
えりか：そこで今日は、セブン・ローソン・ファミマのマーラータンを比較していくね。

【画面演出】チャンネル名「🔬 プチ得ラボ」を表示
```

## 反映対象テンプレート（6種）

- 比較型（2項目）
- 比較型（3項目）
- おすすめ〇選型
- 雑学系
- 単品ディープダイブ型
- 定点観測・値上げ値下げ追跡型

いずれのテンプレートも、「導入」セクションの一番先頭にこの4ステップ構成を適用し、
既存の「期待感リアクション」「進行の一言」等は、チャンネル名画面のあとに続ける形にする。

## 尺への影響

あるあるフックの追加（目安+5〜10秒）により、各テンプレートの導入は
これまでの約45秒から約55秒（+10秒）に拡大する。一方、「はじめに」バッジ用に
別途確保していた時間はなく、バッジはチャンネル名画面の表示に置き換わるだけなので、
純増分はあるあるフックの分のみとなる。

総尺を10分ちょうどに収めたい場合は、増えた分（約10秒）を総括パートから
短縮するなど、どこか別の箇所で微調整する。無理に導入を短縮する必要はない。
各テンプレートファイルの「全体構成」表は、この調整を反映済み。

## 運用ルール

- この4ステップ構成のオープニングは、**チャンネルの通常運用（2本目以降）でも毎回入れる**方針とする
- 以前検討した「初回動画のみフル自己紹介、以降は名前テロップのみ」という案からは変更し、
  短い固定フレーズ＋あるあるフックとして定着させることで、視聴者への安心感と
  ブランド認知、共感による引き込みを両立させる

## パート切り替え時の「章タイトル」演出（全テンプレ共通）

比較型など、複数の対象（企業・商品など）を順番に扱うテンプレートでは、
各パートが始まる直前に、以下の演出を挿入する。

- 単色の図形（画面全体を覆うサイズ、チャンネルカラー系の色）を配置
- その中央に、これから扱う対象名（例：「セブンイレブン」）のテキストを重ねる
- 図形・テキストの両方に「フェードイン・アウト」エフェクトを適用
- 表示時間は1〜2秒程度の短さにする
- 図形とテキストはグループ化しておき、他のパートにも複製して使い回す

この演出により、視聴者が「新しいパートが始まった」ことを
字幕を読まなくても直感的に把握できるようにする。

## 固有名詞・シリーズ名の事実確認ルール（全テンプレ共通）

台本内で、企業の商品シリーズ名・キャンペーン名・製法名などの
固有名詞を使う場合は、必ず一度、実在するかWeb検索等で確認すること。

- AIが生成した固有名詞は、実在しない名称（ハルシネーション）である
  可能性があるため、公開前に必ず裏取りを行う
- 確認が取れない固有名詞は、使用せず、一般的な表現に置き換える
  （例：「おにぎり屋シリーズ」→確認できなければ「変わり種シリーズ」
  のような、固有名詞に依存しない表現にする）
- 価格情報と同様に、固有名詞も「事実確認が必要な情報」として扱う
