
# 台本テンプレート：比較型（2項目）

想定尺：約10分／型：比較（2つのアイテム・お店などを深掘りしながら比較する構成）

## 全体構成

| セクション | 目安時間 | 目安文字数 | 内容 |
|---|---|---|---|
| 導入 | 0:00〜0:55 | 約295字 | 名乗り＋あるあるフック＋お題提示（本題への接続）、チャンネル名画面 |
| 商品①パート | 0:55〜4:10（約3:15） | 約1,050字 | 価格・特徴紹介＋αの切り口、リアクション |
| 商品②パート | 4:10〜7:25（約3:15） | 約1,050字 | 同上 |
| 総括 | 7:25〜9:30（約2:05） | 約670字 | 2つの比較表、利用シーンごとの住み分け提示、視聴者への問いかけ |
| エンディング | 9:30〜10:00 | 約160字 | 締めの挨拶、チャンネル登録案内 |
| **合計目安** | **約10分** | **約3,220字** | |

導入はあるあるフック追加分（約+10秒）を、総括を約10秒短縮することで吸収し、総尺約10分を維持している。
3項目テンプレとの違い：アイテムが1つ減る分、各パートの尺を約1分拡大し、基本情報に加えて「+αの切り口」を1つ追加することで尺を持たせる。

### 目安文字数の算出方法

実測の読み上げ速度（えりか・ここなのセリフ平均、句読点・記号含む、話者名は除く）は**約346文字/分**。
ここに、画像表示・間（テロップ表示や商品カット等でセリフの止まる時間）を考慮した実効係数**0.93**を掛けて算出している。

```
目安文字数 ＝ セクションの秒数 ÷ 60 × 346 × 0.93
```

台本作成時は、この文字数を各パートのセリフ量の目安とし、極端に不足しないようにする。

## 各セクションのセリフ骨格

### 導入（4ステップ構成）
- えりか：どうも、えりかです。
- ここな：ここなだよ！
- 【あるあるフック・1段階目】えりか：テーマ名には触れず、もう一段階広い日常のシーン・悩みを問いかける
  （例：「まとめ買いする時とか、どっちにしようか売り場で迷うことってない？」）
- 【あるあるフック・2段階目】ここな：その日常シーンへの答えとして、自然とテーマのジャンルに触れる形で共感を返す
  （例：「うちはいつも直感で選んじゃって、あとで後悔すること多いかも」）
- えりか：軽い相槌・橋渡しの一言（例：「わかる、選ぶ基準ってなかなか難しいよね」）
- 【本題への接続】えりか：「そこで今日は、〇〇と△△をじっくり比較していくね」（ここで初めて具体的な比較対象2つを明示）
- 【画面演出】チャンネル名「🔬 プチ得ラボ」を表示
- ここな：期待感を出すリアクション
- えりか：進行の一言（「じっくり見比べていこう」）

### 商品パート（①②共通の型）
- えりか：価格・基本情報の紹介（単価換算などを含める）
- ここな：金額や見た目への感想
- えりか：特徴・差別化ポイントの説明
- ここな：共感 or 意外性のあるリアクション
- えりか：+αの切り口の提示（例：まとめ買い向き／個包装で使いやすい／アレンジのしやすさ等）
- ここな：+αに対する感想
- えりか：一言まとめ（次のパートへの繋ぎ）

【テロップ挿入】：商品名・価格・特徴を一覧化したカードを表示
【画像挿入】：商品イメージ（AI生成イラスト／なければテロップカードで代替）

### 総括
- えりか：2つの比較を一覧表で振り返る
- えりか：利用シーンごとの住み分けを明確に提示（「甲乙つけがたい」で終わらせない）
- ここな：自分の好みを一言（視聴者との共感ポイント）
- えりか・ここな：視聴者へのコメント誘導（「あなたはどっち派？」）

【テロップ挿入】：2項目比較表

### エンディング
- えりか：まとめの一言
- ここな：次回予告 or チャンネル登録案内
- えりか・ここな：締めの挨拶

## 画像調達の優先順位（フォールバックルール）

3項目テンプレと共通。
1. AI画像生成で商品の一般的特徴を表現したイラスト（ロゴ・パッケージの正確な再現はしない）
2. 上記が難しい場合、商品名・特徴を大きな文字カードで見せるテロップメイン構成に切り替え
3. 商品固有ではなく、料理ジャンルとして一般化した画像で代用
4. キャラクターの表情差分（驚き・納得など）で間を持たせる
