# 台本テンプレート：おすすめ〇選型

想定尺：約10分／型：ランキング形式で複数アイテムを紹介する構成（基本は5選）

## 全体構成

| セクション | 目安時間 | 目安文字数 | 内容 |
|---|---|---|---|
| 導入 | 0:00〜0:55 | 約295字 | 名乗り＋あるあるフック＋テーマ提示（本題への接続）、チャンネル名画面 |
| 5位パート | 0:55〜2:15（約1:20） | 約430字 | 商品紹介、ひとことポイント |
| 4位パート | 2:15〜3:35（約1:20） | 約430字 | 同上 |
| 3位パート | 3:35〜4:55（約1:20） | 約430字 | 同上 |
| 2位パート | 4:55〜6:15（約1:20） | 約430字 | 同上 |
| 1位パート | 6:15〜7:25（約1:10、やや厚め） | 約380字 | 商品紹介＋選定理由を強調 |
| 総括 | 7:25〜9:30（約2:05） | 約670字 | 5選まとめ一覧、視聴者への問いかけ |
| エンディング | 9:30〜10:00 | 約160字 | 締めの挨拶、チャンネル登録案内 |
| **合計目安** | **約10分** | **約3,220字** | |

導入はあるあるフック追加分（約+10秒）を、総括を約10秒短縮することで吸収し、総尺約10分を維持している。

件数を変える場合（3選／10選など）は、1アイテムあたりの尺は概ね1:00〜1:30を目安に、総尺10分に収まるよう件数を調整する。
文字数目安も同じ比率（1アイテムあたり約80秒×0.93×346÷60 ≒ 約380〜430字）で件数分を再配分する。

### 目安文字数の算出方法

実測の読み上げ速度（えりか・ここなのセリフ平均、句読点・記号含む、話者名は除く）は**約346文字/分**。
ここに、画像表示・間（テロップ表示や商品カット等でセリフの止まる時間）を考慮した実効係数**0.93**を掛けて算出している。

```
目安文字数 ＝ セクションの秒数 ÷ 60 × 346 × 0.93
```

台本作成時は、この文字数を各パートのセリフ量の目安とし、極端に不足しないようにする。

## 各セクションのセリフ骨格

セリフのリズム（えりかが2〜3文連続で話す等の不均等な構成）、ここなのリアクションの強弱（無言／短い相槌／通常／長めの感想を偏りなく織り交ぜる）、語尾・言葉選びのバリエーションは、02-characters.md の「セリフのリズム・バリエーション（重要）」を必ず反映すること。以下の骨格は基本の型であり、そのまま1往復ずつ機械的に書き写さないこと。

### 導入（4ステップ構成）
- えりか：どうも、えりかです。
- ここな：ここなだよ！
- 【あるあるフック・1段階目】えりか：テーマ名には触れず、もう一段階広い日常のシーン・悩みを問いかける
  （例：「棚の前でいろいろあって、結局どれにするか決めきれなくなること、ない？」）
- 【あるあるフック・2段階目】ここな：その日常シーンへの答えとして、自然とテーマのジャンルに触れる形で共感を返す
  （例：「うちもコンビニの棚の前で毎回悩んじゃうかも……」）
- えりか：軽い相槌・橋渡しの一言（例：「だよね、選択肢が多いと逆に迷うんだよね」）
- 【本題への接続】えりか：「そこで今日は、〇〇のおすすめ5選を紹介するよ」（ここで初めてテーマを明示）
- 【画面演出】チャンネル名「🔬 プチ得グルメラボ」を表示
- えりか・ここな：プチ得グルメラボ！
- ここな：期待感を出すリアクション
- えりか：進行の一言（「5位から発表していくね」）

### 各順位パート（共通の型）
- えりか：商品名・価格・順位の紹介
- ここな：感想やリアクション
- えりか：選んだ理由・特徴の説明（1〜2文）
- ここな：選定理由の性質に応じたリアクション（下記「ここなのリアクションパターン」参照）
- （1位のみ）えりか：総合的な選定理由を強調
- （1位のみ）ここな：「ついに1位！」など特別感のあるリアクション

【テロップ挿入】：順位・商品名・価格・ひとことポイントをカードで表示
【画像挿入】：商品イメージ（AI生成イラスト／なければテロップカードで代替）。1位のみ画像をやや大きく扱う

### 総括
- えりか：〇選のまとめを一覧で振り返る
- ここな：自分が気になった順位を一言
- えりか：用途や好みに応じた選び方のアドバイス
- えりか・ここな：視聴者へのコメント誘導（「あなたのお気に入りは？」）

【テロップ挿入】：〇選まとめ一覧表

### エンディング
- えりか：まとめの一言
- ここな：次回予告 or チャンネル登録案内
- えりか・ここな：締めの挨拶

## ここなのリアクションパターン（重要）

各順位パートでの「選んだ理由・特徴の説明」に対するここなのリアクションは、
「納得・共感」一辺倒にせず、理由の性質に応じて使い分けることで、掛け合いに
メリハリを持たせる。

- **納得・共感**：素直に良さが伝わる理由の場合
  例：「たしかに、それは選ばれる理由が分かるかも」
- **ツッコミ**：選ばれた理由が意外だったり、拍子抜けするほどシンプルだったりする場合
  例：「え、それだけの理由なの！？」「そんなことある！？」
- **驚き**：順位や理由が予想外だった場合
  例：「え、それがこの順位なんだ！」

5位〜1位まで全て同じリアクションで並べず、商品ごとの理由の性質に応じてパターンを
選ぶこと。

## 画像調達の優先順位（フォールバックルール）

比較型テンプレと共通。
1. AI画像生成で商品の一般的特徴を表現したイラスト（ロゴ・パッケージの正確な再現はしない）
2. 上記が難しい場合、商品名・特徴を大きな文字カードで見せるテロップメイン構成に切り替え
3. 商品固有ではなく、料理ジャンルとして一般化した画像で代用
4. キャラクターの表情差分（驚き・納得など）で間を持たせる

## 比較型との違い

- 比較型は「横並びで公平に見比べる」構成、おすすめ〇選型は「順位付けにより期待感・カウントダウン感を演出する」構成
- 1位パートのみ特別扱い（画像を大きくする、理由を厚めに説明する）にすることで、視聴者を最後まで引きつける設計にしている
