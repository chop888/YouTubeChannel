# 台本テンプレート：比較型（3項目）

想定尺：約10分／型：比較（3社・3商品などを横並びで比較する構成）

## 全体構成

| セクション | 目安時間 | 目安文字数 | 内容 |
|---|---|---|---|
| 導入 | 0:00〜0:55 | 約295字 | 名乗り＋あるあるフック＋お題提示（本題への接続）、チャンネル名画面 |
| 商品①パート | 0:55〜3:10（約2:15） | 約720字 | 価格・特徴紹介、リアクション |
| 商品②パート | 3:10〜5:25（約2:15） | 約720字 | 同上 |
| 商品③パート | 5:25〜7:40（約2:15） | 約720字 | 同上 |
| 総括 | 7:40〜9:30（約1:50） | 約590字 | 3つの比較表、軸ごとのおすすめ提示、視聴者への問いかけ |
| エンディング | 9:30〜10:00 | 約160字 | 締めの挨拶、チャンネル登録案内 |
| **合計目安** | **約10分** | **約3,200字** | |

導入はあるあるフック追加分（約+10秒）を、総括を約10秒短縮することで吸収し、総尺約10分を維持している。

### 目安文字数の算出方法

実測の読み上げ速度（えりか・ここなのセリフ平均、句読点・記号含む、話者名は除く）は**約346文字/分**。
ここに、画像表示・間（テロップ表示や商品カット等でセリフの止まる時間）を考慮した実効係数**0.93**を掛けて算出している。

```
目安文字数 ＝ セクションの秒数 ÷ 60 × 346 × 0.93
```

台本作成時は、この文字数を各パートのセリフ量の目安とし、極端に不足しないようにする。

## 各セクションのセリフ骨格

### 導入（4ステップ構成）
- えりか：どうも、えりかです。
- ここな：ここなだよ！
- 【あるあるフック・1段階目】えりか：テーマ名には触れず、もう一段階広い日常のシーン・悩みを問いかける
  （例：「小腹が空いた時とか、ちょっとした贅沢がしたい時ってどうしてる？」）
- 【あるあるフック・2段階目】ここな：その日常シーンへの答えとして、自然とテーマのジャンルに触れる形で共感を返す
  （例：「うち、最近は〇〇系にハマってて、それで満足してるかも」）
- えりか：軽い相槌・橋渡しの一言（例：「だよね、あれ手軽に満足感あるもんね」）
- 【本題への接続】えりか：「そこで今日は、〇〇と△△と□□を比較していくね」（ここで初めて具体的な比較対象3つを明示）
- 【画面演出】チャンネル名「🔬 プチ得グルメラボ」を表示
- えりか・ここな：プチ得グルメラボ！
- ここな：期待感を出すリアクション
- えりか：進行の一言（「さっそく1つ目から見ていこう」）

### 商品パート（①〜③共通の型）
- えりか：価格・基本情報の紹介
- ここな：金額や見た目への感想
- えりか：特徴・差別化ポイントの説明（例：具材、味の傾向、量など）
- ここな：共感 or 意外性のあるリアクション
- えりか：一言まとめ（次のパートへの繋ぎ）

【テロップ挿入】：商品名・価格・特徴を一覧化したカードを表示
【画像挿入】：商品イメージ（AI生成イラスト／なければテロップカードで代替）

### 総括
- えりか：3つの比較を一覧表で振り返る
- えりか：軸ごとのおすすめ提示（例：コスパ重視なら〇〇、こだわり重視なら△△）
- ここな：自分の好みを一言（視聴者との共感ポイント）
- えりか・ここな：視聴者へのコメント誘導（「あなたはどれ派？」）

【テロップ挿入】：3社比較表

### エンディング
- えりか：まとめの一言
- ここな：次回予告 or チャンネル登録案内
- えりか・ここな：締めの挨拶

## 画像調達の優先順位（フォールバックルール）

1. AI画像生成で商品の一般的特徴を表現したイラスト（ロゴ・パッケージの正確な再現はしない）
2. 上記が難しい場合、商品名・特徴を大きな文字カードで見せるテロップメイン構成に切り替え
3. 商品固有ではなく、料理ジャンルとして一般化した画像で代用
4. キャラクターの表情差分（驚き・納得など）で間を持たせる

## 2項目比較にする場合の変更点

- 各商品パートを約3:00〜3:30に拡大し、価格・特徴に加えて「+αの切り口」（例：アレンジ方法、こんな人におすすめ等）を1つ追加する
- 総括は「甲乙つけがたい」で終わらせず、軸ごとに明確に住み分けて紹介する（例：コスパ重視ならA、量重視ならB）
