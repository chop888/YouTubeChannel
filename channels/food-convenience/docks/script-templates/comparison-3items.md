# 台本テンプレート：比較型（3項目）

想定尺：約10分／型：比較（3社・3商品などを横並びで比較する構成）

## 全体構成

| セクション | 目安時間 | 内容 |
|---|---|---|
| 導入 | 0:00〜0:45 | お題提示、今日比較する3つを紹介 |
| 商品①パート | 0:45〜3:00（約2:15） | 価格・特徴紹介、リアクション |
| 商品②パート | 3:00〜5:15（約2:15） | 同上 |
| 商品③パート | 5:15〜7:30（約2:15） | 同上 |
| 総括 | 7:30〜9:30 | 3つの比較表、軸ごとのおすすめ提示、視聴者への問いかけ |
| エンディング | 9:30〜10:00 | 締めの挨拶、チャンネル登録案内 |

## 各セクションのセリフ骨格

### 導入
- えりか：今日のお題提示（「〇〇と△△と□□を比較していくね」）
- ここな：期待感を出すリアクション
- えりか：進行の一言（「さっそく1つ目から見ていこう」）

### 商品パート（①〜③共通の型）
- えりか：価格・基本情報の紹介
- ここな：金額や見た目への感想
- えりか：特徴・差別化ポイントの説明（例：具材、味の傾向、量など）
- ここな：共感 or 意外性のあるリアクション
- えりか：一言まとめ（次のパートへの繋ぎ）

【テロップ挿入】：商品名・価格・特徴を一覧化したカードを表示
【画像挿入】：商品イメージ（AI生成イラスト／なければテロップカードで代替）

### 総括
- えりか：3つの比較を一覧表で振り返る
- えりか：軸ごとのおすすめ提示（例：コスパ重視なら〇〇、こだわり重視なら△△）
- ここな：自分の好みを一言（視聴者との共感ポイント）
- えりか・ここな：視聴者へのコメント誘導（「あなたはどれ派？」）

【テロップ挿入】：3社比較表

### エンディング
- えりか：まとめの一言
- ここな：次回予告 or チャンネル登録案内
- えりか・ここな：締めの挨拶

## 画像調達の優先順位（フォールバックルール）

1. AI画像生成で商品の一般的特徴を表現したイラスト（ロゴ・パッケージの正確な再現はしない）
2. 上記が難しい場合、商品名・特徴を大きな文字カードで見せるテロップメイン構成に切り替え
3. 商品固有ではなく、料理ジャンルとして一般化した画像で代用
4. キャラクターの表情差分（驚き・納得など）で間を持たせる

## 2項目比較にする場合の変更点

- 各商品パートを約3:00〜3:30に拡大し、価格・特徴に加えて「+αの切り口」（例：アレンジ方法、こんな人におすすめ等）を1つ追加する
- 総括は「甲乙つけがたい」で終わらせず、軸ごとに明確に住み分けて紹介する（例：コスパ重視ならA、量重視ならB）
