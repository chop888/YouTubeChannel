# 共通オープニング（全テンプレ共通・固定）

チャンネル名決定（プチ得ラボ）に伴い、すべての台本テンプレートの「導入」セクションの
一番最初に、以下の固定挨拶を必ず挿入する。

## 固定セリフ（約5秒）

```
えりか：どうも、えりかです。
ここな：ここなだよ！
えりか：プチ得ラボ、始めていくね。
```

この直後に、各テンプレ本来の導入（お題提示・つかみのフレーズ）を続ける。

### 例：比較型（3項目）の場合

```
えりか：どうも、えりかです。
ここな：ここなだよ！
えりか：プチ得ラボ、始めていくね。
えりか：いきなりだけど、みんなマーラータンって好き？
ここな：うちめっちゃ好き！最近ハマってて、週2くらいで食べてるかも。
えりか：今日はセブン・ローソン・ファミマ、比較していくね。
```

## 反映対象テンプレート（6種）

- 比較型（2項目）
- 比較型（3項目）
- おすすめ〇選型
- 雑学系
- 単品ディープダイブ型
- 定点観測・値上げ値下げ追跡型

いずれのテンプレートも、「導入」セクションの一番先頭にこの固定セリフを追加し、
既存の導入セリフはそのまま後ろに続ける形にする。

## 尺への影響

固定挨拶の分（約5秒）だけ、各テンプレートの全体尺がわずかに伸びる。
総尺を10分ちょうどに収めたい場合は、総括パートを数秒短縮するなど、
どこか別の箇所で微調整する。無理に導入を短縮する必要はない。

## 運用ルール

- この固定挨拶は、**チャンネルの通常運用（2本目以降）でも毎回入れる**方針とする
- 以前検討した「初回動画のみフル自己紹介、以降は名前テロップのみ」という案からは変更し、
  短い固定フレーズとして定着させることで、視聴者への安心感とブランド認知を優先する
