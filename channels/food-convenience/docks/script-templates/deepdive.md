# 台本テンプレート：単品ディープダイブ型

想定尺：約10分／型：1つの商品を多角的に深掘り紹介する構成（比較・順位付けを行わない）

## 全体構成

| セクション | 目安時間 | 目安文字数 | 内容 |
|---|---|---|---|
| 導入 | 0:00〜0:55 | 約295字 | 名乗り＋あるあるフック＋商品提示（本題への接続）、チャンネル名画面 |
| 基本情報パート | 0:55〜2:40 | 約560字 | 価格・内容量・単価の紹介 |
| 特徴・こだわりパート | 2:40〜4:40 | 約640字 | 商品の特徴、他と違う点の紹介 |
| 評判レポートパート | 4:40〜6:40 | 約640字 | 口コミ・レビューのまとめ、または実食レポート |
| アレンジ提案パート | 6:40〜8:10 | 約480字 | アレンジ方法の提案（1〜2つ） |
| 総括 | 8:10〜9:30（約1:20） | 約430字 | まとめ、おすすめ度、視聴者への問いかけ |
| エンディング | 9:30〜10:00 | 約160字 | 締めの挨拶、チャンネル登録案内 |
| **合計目安** | **約10分** | **約3,200字** | |

導入はあるあるフック追加分（約+10秒）を、総括を約10秒短縮することで吸収し、総尺約10分を維持している。

### 目安文字数の算出方法

実測の読み上げ速度（えりか・ここなのセリフ平均、句読点・記号含む、話者名は除く）は**約346文字/分**。
ここに、画像表示・間（テロップ表示や商品カット等でセリフの止まる時間）を考慮した実効係数**0.93**を掛けて算出している。

```
目安文字数 ＝ セクションの秒数 ÷ 60 × 346 × 0.93
```

台本作成時は、この文字数を各パートのセリフ量の目安とし、極端に不足しないようにする。

## 評判レポートパートの運用ルール（重要）

「実食コメント」を毎回AIが生成すると、実際には食べていない体験を事実のように語ることになり、誠実性の観点で問題がある。以下の運用を基本とする。

- **基本（自動化対応）**：SNS・レビューサイト等の口コミをリサーチし、「口コミでは〜という声が多い」という体裁でまとめる。実際の体験として語らない。
- **差別化回（人の関与あり）**：気になる商品や反応が良かった商品は、実際に購入して試食し、「実食レポート」として明確に区別して紹介する。
- どちらの形式かは、台本内で明確に区別できるようにしておく（例：口コミまとめ回は「評判をまとめると」、実食回は「実際に食べてみると」のように言葉を使い分ける）。

## 各セクションのセリフ骨格

### 導入（4ステップ構成）
- えりか：どうも、えりかです。
- ここな：ここなだよ！
- 【あるあるフック・1段階目】えりか：テーマ名には触れず、もう一段階広い日常のシーン・悩みを問いかける
  （例：「なんとなく買ったことはあっても、じっくり知る機会ってなかったりしない？」）
- 【あるあるフック・2段階目】ここな：その日常シーンへの答えとして、自然とテーマのジャンルに触れる形で共感を返す
  （例：「うちも普段何気なく手に取ってるだけで、詳しくは知らないかも」）
- えりか：軽い相槌・橋渡しの一言（例：「だよね、知ると意外な発見があったりするんだよね」）
- 【本題への接続】えりか：「そこで今日は、〇〇を1つだけ、とことん深掘りしていくよ」（ここで初めて商品名を明示）
- 【画面演出】チャンネル名「🔬 プチ得ラボ」を表示
- ここな：期待感のあるリアクション
- えりか：進行の一言

### 基本情報パート
- えりか：価格・内容量・単価の紹介
- ここな：金額への感想（お得感など）

### 特徴・こだわりパート
- えりか：商品の特徴、他商品との違いを説明
- ここな：驚き・共感のリアクション

### 評判レポートパート（口コミまとめ版）
- えりか：口コミ・レビューの傾向を紹介（「評判を見てみると〜という声が多いよ」）
- ここな：気になる・試したくなるリアクション

### 評判レポートパート（実食版・差別化回のみ）
- えりか：実際に食べた感想（味・食感・注意点など）
- ここな：気になる・試したくなるリアクション

【画像挿入】：完成イメージ（AI生成イラスト／なければテロップカードで代替）

### アレンジ提案パート
- えりか：アレンジ方法の提案（1〜2つ）
- ここな：追加のアレンジ案や感想

【テロップ挿入】：アレンジ案を箇条書きでカード表示

### 総括
- えりか：まとめ、おすすめ度の提示
- ここな：自分の感想を一言
- えりか・ここな：視聴者へのコメント誘導（「試した感想を教えてね」）

【テロップ挿入】：価格・特徴・おすすめアレンジのまとめ表

### エンディング
- えりか：まとめの一言
- ここな：次回予告 or チャンネル登録案内
- えりか・ここな：締めの挨拶

## この型の位置づけ

- 比較対象・順位付けが不要なため、**新商品が出るたびに単発で量産しやすい**
- ネタ切れ防止の要となる型。他の型（比較・〇選・雑学）でテーマが見つからない週の穴埋めとしても機能する
- 評判レポートパートは基本自動化、実食は月1〜2回など頻度を決めて人が担当する想定

## 画像調達の優先順位（フォールバックルール）

他テンプレと共通。
1. AI画像生成で一般的な特徴を表現したイラスト
2. 大きな文字カードによるテロップメイン構成
3. 商品固有ではなく一般化した画像で代用
4. キャラクターの表情差分で間を持たせる
