# 台本テンプレート：単品ディープダイブ型

想定尺：約10分／型：1つの料理・食べ物を多角的にじっくり深掘り紹介する構成（比較・順位付けを行わない）

## 全体構成

| セクション | 目安時間 | 目安文字数 | 内容 |
|---|---|---|---|
| 導入 | 0:00〜0:55 | 約295字 | 名乗り＋あるあるフック＋料理提示（本題への接続）、チャンネル名画面 |
| 基本情報パート | 0:55〜1:55 | 約320字 | どんな料理か、簡単な説明（見た目・味の特徴など） |
| 由来・誕生秘話パート | 1:55〜3:40 | 約560字 | いつ、どこで、どうして生まれたか |
| 広がり・変化パート | 3:40〜5:25 | 約560字 | どう広まったか、地域差、時代による食べられ方の変化 |
| バリエーション・派生パート | 5:25〜7:10 | 約560字 | ご当地版・アレンジ版などのバリエーション |
| 意外なエピソードパート | 7:10〜9:40 | 約800字 | 面白い記録・こぼれ話（**この型で一番盛り上がる、最もボリュームを割くパート**） |
| 短い締め | 9:40〜10:00 | 約110字 | 最後のエピソードを受けた短い一言感想のみ（総括・チャンネル登録案内は行わない） |
| **合計目安** | **約10分** | **約3,205字** | |

導入はあるあるフック追加分（約+10秒）を吸収した上で、時間配分・目安文字数を再計算している。
従来あった「総括」（振り返り）と「エンディング」（チャンネル登録案内など）は、1つの短い
「短い締め」パートに統合・大幅縮小し、浮いた尺は「意外なエピソードパート」に重点配分している。

### 目安文字数の算出方法

実測の読み上げ速度（えりか・ここなのセリフ平均、句読点・記号含む、話者名は除く）は**約346文字/分**。
ここに、画像表示・間（テロップ表示や関連カット等でセリフの止まる時間）を考慮した実効係数**0.93**を掛けて算出している。

```
目安文字数 ＝ セクションの秒数 ÷ 60 × 346 × 0.93
```

台本作成時は、この文字数を各パートのセリフ量の目安とし、極端に不足しないようにする。

## 各セクションのセリフ骨格

セリフのリズム（えりかが2〜3文連続で話す等の不均等な構成）、ここなのリアクションの強弱（無言／短い相槌／通常／長めの感想を偏りなく織り交ぜる）、語尾・言葉選びのバリエーションは、02-characters.md の「セリフのリズム・バリエーション（重要）」を必ず反映すること。以下の骨格は基本の型であり、そのまま1往復ずつ機械的に書き写さないこと。

### 導入（4ステップ構成）
- えりか：どうも、えりかです
- ここな：ここなだよ！
- 【あるあるフック・1段階目】えりか：テーマ名には触れず、もう一段階広い日常のシーン・悩みを問いかける
  （例：「なんとなく食べたことはあっても、じっくり知る機会ってなかったりしませんか」）
- 【あるあるフック・2段階目】ここな：その日常シーンへの答えとして、自然とテーマのジャンルに触れる形で共感を返す
  （例：「うちも普段何気なく食べてるだけで、詳しくは知らないかも」）
- えりか：軽い相槌・橋渡しの一言（例：「知ると意外な発見があります」）
- 【本題への接続】えりか：「そこで今日は、〇〇を1つだけ、とことん深掘りしていきます」（ここで初めて料理名を明示）
- 【画面演出】チャンネル名「🔬 プチ得グルメラボ」を表示
- えりか・ここな：プチ得グルメラボ！
- ここな：期待感のあるリアクション
- えりか：進行の一言

### 基本情報パート
- えりか：どんな料理か、簡単な説明（見た目・味の特徴・どんな場面で食べられるものかなど）
- ここな：初見・素朴な感想

### 由来・誕生秘話パート
- えりか：いつ、どこで、どうして生まれたかを紹介
- ここな：誕生エピソードの性質に応じたリアクション（下記「ここなのリアクションパターン」参照）

【テロップ挿入】：発祥地・誕生年など、確認できた事実を要点カードで表示

### 広がり・変化パート
- えりか：どう広まっていったか、地域による違い、時代による食べられ方の変化を紹介
- ここな：気づき・共感のリアクション

### バリエーション・派生パート
- えりか：ご当地版・アレンジ版などのバリエーションを紹介
- ここな：気になる・試したくなるリアクション

【テロップ挿入】：バリエーション一覧をカード表示

### 意外なエピソードパート（この型で一番盛り上がるパート）
- えりか：面白い記録・こぼれ話を紹介。他パートより多めのネタ数・分量を割いてよい
- ここな：驚き・意外性に応じたリアクション

【画像挿入】：完成イメージ・関連画像（AI生成イラスト／なければテロップカードで代替）

### 短い締め（総括ではない）
- えりか：最後に紹介したエピソードを受けた、短い一言感想（1文程度）
- ここな：短い一言感想（1文程度）。自然な流れであれば「知ってるエピソードがあれば教えてね」
  のようなコメント誘導を添えてもよいが、無理に入れなくてよい
- えりか・ここな：締めの挨拶（「ばいばーい」等）

これまでの台本にあった「今日はこんな内容でした」という振り返り・まとめの総括、および
「チャンネル登録・高評価お願いします」のような呼びかけは、セリフからもテロップからも
**入れない**。意外なエピソードパートの勢いのまま、短く締めること。

## ここなのリアクションパターン（重要）

各パート、特に「由来・誕生秘話パート」「意外なエピソードパート」でのここなのリアクションは、
「驚き・共感」一辺倒にせず、紹介される内容の性質に応じて使い分けることで、掛け合いにメリハリを持たせる。

- **驚き・納得**：意外性があり、聞くと腑に落ちる由来・エピソードの場合
  例：「え、そんな理由で生まれたんだ！」
- **ツッコミ**：由来や理由が拍子抜けするほどシンプル、または少し意外に感じられる場合
  例：「え、それだけの理由なの！？」「そんなことある！？」
- **共感**：身近で「あるある」と感じられる内容の場合
  例：「それは分かるかも」

## この型の位置づけ

- チャンネルコンセプト上、雑学系と並ぶ**主力の型**。ご当地グルメ・郷土料理・歴史的な食べ物を
  中心に、切り口が尽きにくく単発で量産しやすい
- 由来・広がり・バリエーション・エピソードの4パートで多角的に掘り下げるため、
  比較・順位付けを行わなくても1本として成立する
- 発祥地・誕生年など、事実確認が必要な情報が多い型のため、下記「画像調達の優先順位」に加えて、
  00_common_opening_template.md の「固有名詞・シリーズ名の事実確認ルール」を特に厳密に適用すること

## 画像調達の優先順位（フォールバックルール）

他テンプレと共通。
1. AI画像生成で一般的な特徴を表現したイラスト
2. 大きな文字カードによるテロップメイン構成
3. 商品固有ではなく一般化した画像で代用
4. キャラクターの表情差分で間を持たせる
