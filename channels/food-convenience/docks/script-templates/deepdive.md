# 台本テンプレート：単品ディープダイブ型

想定尺：約10分／型：1つの商品を多角的に深掘り紹介する構成（比較・順位付けを行わない）

## 全体構成

| セクション | 目安時間 | 内容 |
|---|---|---|
| 導入 | 0:00〜0:45 | 商品提示、今日は1つを深掘りする旨を予告 |
| 基本情報パート | 0:45〜2:30 | 価格・内容量・単価の紹介 |
| 特徴・こだわりパート | 2:30〜4:30 | 商品の特徴、他と違う点の紹介 |
| 評判レポートパート | 4:30〜6:30 | 口コミ・レビューのまとめ、または実食レポート |
| アレンジ提案パート | 6:30〜8:00 | アレンジ方法の提案（1〜2つ） |
| 総括 | 8:00〜9:30 | まとめ、おすすめ度、視聴者への問いかけ |
| エンディング | 9:30〜10:00 | 締めの挨拶、チャンネル登録案内 |

## 評判レポートパートの運用ルール（重要）

「実食コメント」を毎回AIが生成すると、実際には食べていない体験を事実のように語ることになり、誠実性の観点で問題がある。以下の運用を基本とする。

- **基本（自動化対応）**：SNS・レビューサイト等の口コミをリサーチし、「口コミでは〜という声が多い」という体裁でまとめる。実際の体験として語らない。
- **差別化回（人の関与あり）**：気になる商品や反応が良かった商品は、実際に購入して試食し、「実食レポート」として明確に区別して紹介する。
- どちらの形式かは、台本内で明確に区別できるようにしておく（例：口コミまとめ回は「評判をまとめると」、実食回は「実際に食べてみると」のように言葉を使い分ける）。

## 各セクションのセリフ骨格

### 導入
- えりか：商品提示（「今日は〇〇を1つだけ深掘りするよ」）
- ここな：期待感のあるリアクション
- えりか：進行の一言

### 基本情報パート
- えりか：価格・内容量・単価の紹介
- ここな：金額への感想（お得感など）

### 特徴・こだわりパート
- えりか：商品の特徴、他商品との違いを説明
- ここな：驚き・共感のリアクション

### 評判レポートパート（口コミまとめ版）
- えりか：口コミ・レビューの傾向を紹介（「評判を見てみると〜という声が多いよ」）
- ここな：気になる・試したくなるリアクション

### 評判レポートパート（実食版・差別化回のみ）
- えりか：実際に食べた感想（味・食感・注意点など）
- ここな：気になる・試したくなるリアクション

【画像挿入】：完成イメージ（AI生成イラスト／なければテロップカードで代替）

### アレンジ提案パート
- えりか：アレンジ方法の提案（1〜2つ）
- ここな：追加のアレンジ案や感想

【テロップ挿入】：アレンジ案を箇条書きでカード表示

### 総括
- えりか：まとめ、おすすめ度の提示
- ここな：自分の感想を一言
- えりか・ここな：視聴者へのコメント誘導（「試した感想を教えてね」）

【テロップ挿入】：価格・特徴・おすすめアレンジのまとめ表

### エンディング
- えりか：まとめの一言
- ここな：次回予告 or チャンネル登録案内
- えりか・ここな：締めの挨拶

## この型の位置づけ

- 比較対象・順位付けが不要なため、**新商品が出るたびに単発で量産しやすい**
- ネタ切れ防止の要となる型。他の型（比較・〇選・雑学）でテーマが見つからない週の穴埋めとしても機能する
- 評判レポートパートは基本自動化、実食は月1〜2回など頻度を決めて人が担当する想定

## 画像調達の優先順位（フォールバックルール）

他テンプレと共通。
1. AI画像生成で一般的な特徴を表現したイラスト
2. 大きな文字カードによるテロップメイン構成
3. 商品固有ではなく一般化した画像で代用
4. キャラクターの表情差分で間を持たせる
